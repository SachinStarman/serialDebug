Serial Debug Assistant Pro — User Guide

A professional-grade serial debug tool supporting Serial, TCP, and UDP connections with real-time waveform visualization, scripting, command automation, and split-view analysis.

Connection Setup

Serial (UART)

Select your COM port from the dropdown (click 🔄 to refresh), set Baud Rate (default 115200), Data Bits (5-8), Parity, Stop Bits, and Flow Control. Click Connect.

TCP Client / Server

Client: Enter host IP and port, then connect. Server: Enter a port to listen on; incoming connections are shown via toast notifications.

UDP

Bind to a Local Port for receiving. Set Remote Host and Remote Port for sending. UDP is connectionless — data is sent/received immediately.

Auto-Reconnect

Enable the Auto-Reconnect checkbox to retry the connection automatically every 3 seconds if it drops (Serial only).

Monitor

Display Modes

  • String — Decoded text (UTF-8, ASCII, GBK, Latin-1)
  • HEX — Raw bytes as hexadecimal: 48 65 6C 6C 6F
  • Both — Side-by-side hex + ASCII view

Frame Breaking

Enable Auto Frame Break to group bytes into frames based on idle gap (default 50ms). Useful for protocols without explicit delimiters.

Other Options

  • Timestamp — Prefix each frame with [14:30:05.123]
  • Auto Scroll — Keep display scrolled to latest data
  • Pause — Freeze display (data still captured in background)
  • Search — Filter frames by text (toggle RX/TX independently)

Sending Data

Type in the send bar at bottom. Press Enter to send, Shift+Enter for newline. Options: \n / \r append, String/HEX mode, Auto-Repeat.

Send History: Press ↑/↓ arrows to navigate previously sent commands (up to 100 stored).

Waveform Visualizer

Data Format

Your device must send one line per sample, terminated with \n. Supported formats:

Key-Value Pairs (recommended)
temperature:23.5,pressure:1013.2,humidity:65.0\n
temp=23.5, hum=65.2\n
Plain CSV (auto-labeled CH1, CH2, ...)
100,200,300\n
23.5 65.2 1013\n

Display Mode

Oscilloscope-style view. X-axis = time (ms/div), Y-axis = amplitude/div. Use the scale bar below the chart to control Amp/div, Y-offset, and ms/div per view.

Timing Mode

  • Auto — Uses real timestamps from when data arrives. Best for variable-rate streams.
  • Manual — Uses your defined data rate (ms/point) for uniform spacing. Best for fixed-rate hardware.

Channel Legend

Each detected channel appears with its color. Click the color dot in the toolbar to open Channel Config where you can rename channels, change colors, set scale/offset.

Data Sampling

For high-frequency streams, enable Data Sampling to process every Nth point (reduces CPU load).

Split-View Waveform

Create multiple independent waveform charts for comparing different channels side by side.

Creating Splits

Right-click on any chart → select Split Horizontal ↔ or Split Vertical ↕.

Per-View Controls

  • Legend bar — Shows ALL channels as colored dots. Filled = enabled, Hollow = disabled. Click a dot to toggle.
  • Original view — All channels enabled by default.
  • New views — All channels disabled by default. Click dots to enable.
  • Scale bar — Independent Amp/div, Y-offset, ms/div per view.

Managing Views

  • Click a view to activate it (highlighted border)
  • Drag the resizer handle between views to adjust sizes
  • Right-click → Close View to remove (cannot close last view)
  • Right-click → Screenshot to capture view(s) as PNG

Commands (600 Slots)

Store up to 600 commands (paged 20 per page). Each command has a name, data payload, format (String/HEX), and optional notes.

  • Click any empty slot to create a command
  • Click Send to transmit, Edit to modify
  • Use Import/Export to share command sets as JSON

Command Modes

Each command operates in one of three modes, selected in the edit dialog:

① Single Mode (default)
Sends the command once when clicked. No badge shown.
② Repeat Mode (×N badge)
Sends the command N times at a configurable interval.
• Repeat Count: number of sends (default 5)
• Interval (ms): delay between sends (default 500)
Click Send again while running to STOP.
③ Function of Time Mode (f(t) badge)
Sends a dynamically computed value over time.
• Expression: math formula using t (seconds), e.g. sin(2*PI*t)
• Rate (ms): evaluation interval (default 100)
• Duration (s): how long to run (default 5)
• Decimals: number formatting precision

If command Data contains {fn}, the value replaces it:
  Data: "SET_SPEED {fn}"  →  sends "SET_SPEED 1.00"

Macro Keys

Assign keyboard shortcuts to any command. Click the key badge on a card, press any key to assign. Press Escape to remove. Use the Macro Listener box to trigger commands via keyboard.

Math Functions Reference

Available in f(t) mode, Math Channels, and script expressions:

Functions & Constants
sin(x)  cos(x)  tan(x)    — Trigonometric
abs(x)  sqrt(x) log(x)    — Absolute, square root, natural log
pow(x,y) min(a,b) max(a,b) — Power, min, max
round(x) floor(x) ceil(x)  — Rounding
PI (3.14159...)  E (2.71828...) — Constants
t — elapsed time in seconds (f(t) mode)
Example Expressions
sin(2 * PI * t)              — 1 Hz sine wave
sin(t) * 127 + 128           — Sine scaled to 0–255 (PWM)
t < 2 ? 0 : 255              — Step function at t=2s
(t % 1) * 255                — Sawtooth wave, 1 Hz
pow(E, -t*0.5) * sin(t) * 100 — Damped oscillation
t * 10                       — Linear ramp (10 units/sec)

Math Channels

Create computed channels from expressions applied to incoming data. Access via the waveform toolbar.

Examples (reference channel names from your data)
voltage * current        — compute power
(CH1 + CH2) / 2          — average two channels
abs(CH1 - CH2)           — absolute difference
sin(t * 0.1) * CH1       — modulated channel

Sequence

Chain multiple commands with configurable delays for automated test sequences.

  • Add Step — Set data, delay (ms), and format per step
  • ▶ Run — Execute all steps in order
  • Loop — Repeat continuously until stopped
  • Default Delay — Pre-fill delay for new steps

Script Engine

Write JavaScript to automate complex send/receive scenarios. Scripts run in a sandboxed VM with a 5-second startup timeout.

API Reference
send(string)         — Send text over active connection
sendHex("FF 01 02")  — Send raw hex bytes
onData(function(data){}) — Register receive handler
                         (data = byte array)
log(...args)         — Print to script console
console.log(...)     — Same as log()
setTimeout(fn, ms)   — Delayed execution
setInterval(fn, ms)  — Repeated execution
clearTimeout(id)     — Cancel timeout
clearInterval(id)    — Cancel interval
Built-in Objects
Math, Date, JSON, String, Number, Array, Object,
Boolean, RegExp, parseInt, parseFloat, isNaN,
isFinite, Buffer.from(), Buffer.alloc()
Example: Auto-Response
log("Auto-responder started");
onData(function(data) {
  var text = data.map(function(b) {
    return String.fromCharCode(b);
  }).join('').trim();
  if (text === "PING") {
    send("PONG\n");
    log("Replied PONG");
  }
});
Example: Periodic Sensor Poll
var count = 0;
var timer = setInterval(function() {
  send("READ_SENSOR\n");
  count++;
  log("Poll #" + count);
  if (count >= 50) {
    clearInterval(timer);
    log("Done");
  }
}, 500);
Example: Binary Protocol Packet
function sendPacket(cmd, payload) {
  var bytes = [0xAA, 0x55, cmd, payload.length];
  bytes = bytes.concat(payload);
  var checksum = 0;
  for (var i = 0; i < bytes.length; i++)
    checksum ^= bytes[i];
  bytes.push(checksum);
  var hex = bytes.map(function(b) {
    return b.toString(16).padStart(2, '0');
  }).join('');
  sendHex(hex);
  log("Sent CMD=0x" + cmd.toString(16));
}
sendPacket(0x01, [0x00, 0x64]);
Example: Data Parser with Alert
var buffer = "";
onData(function(data) {
  buffer += data.map(function(b) {
    return String.fromCharCode(b);
  }).join('');
  var lines = buffer.split("\n");
  buffer = lines.pop();
  lines.forEach(function(line) {
    line = line.trim();
    if (line.startsWith("TEMP:")) {
      var temp = parseFloat(line.substring(5));
      log("Temperature: " + temp + "°C");
      if (temp > 50) {
        send("ALERT_HIGH_TEMP\n");
        log("⚠ HIGH TEMP!");
      }
    }
  });
});
Example: AT Command Sequence
log("Starting AT test...");
send("AT\r\n");
setTimeout(function() {
  send("AT+GMR\r\n");
}, 1000);
setTimeout(function() {
  send("AT+CWMODE=1\r\n");
}, 2000);
setTimeout(function() {
  send("AT+CWLAP\r\n");
  log("WiFi scan started");
}, 3000);

Important Notes

  • Scripts run in a sandboxed environment — no filesystem or network access
  • Startup timeout is 5 seconds — use setInterval/setTimeout for long tasks
  • Click Stop to cancel all timers and clear handlers
  • Script console retains up to 1000 log entries

Terminal

Full VT100-compatible terminal (xterm.js). Typing sends keystrokes directly to the connection.

  • Local Echo — Enable to see your own typed characters
  • Supports ANSI escape sequences, colors, cursor control
  • Scrollback buffer: 10,000 lines

Split Panel Layout

Run two panels side-by-side. Select a panel from the Split dropdown to open it in the right pane. Drag the divider to resize.

Example workflows:

  • Monitor + Waveform chart side by side
  • Script editor + Terminal output
  • Commands + User Guide for reference

Settings & Themes

Themes

Built-in presets: Midnight (default), Cyberpunk, Forest, Ocean, Sunset. Customize individual colors and save/export your own themes.

Font Sizes

Adjust UI Font Size (general text) and Mono Font Size (monitor/terminal) independently.

Keyboard Shortcuts

  • Enter — Send data from send bar
  • Shift+Enter — New line in send input
  • ↑ / ↓ — Navigate send history
  • Tab (in script editor) — Insert 2 spaces
  • Right-click (on waveform) — Context menu

State Persistence

All settings are saved automatically: connection config, display preferences, commands, repeat/function configs, macro keys, math channels, themes, and send history. Settings persist across app restarts.
